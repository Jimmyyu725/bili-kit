# Bili Kit

面向 Bilibili 的轻量浏览器工具箱，支持字幕提取、评论复制、首页推荐回溯和推广过滤，并兼容 YouTube 字幕。无需额外服务器或插件账号。

现有安装目录仍使用 `caption-lite`，保持原路径；在 Chrome 中重新加载扩展后，显示名称更新为 **Bili Kit**。

## 当前功能

- 自动提取 YouTube 视频提供的全部字幕语言，无需先开启 CC
- 读取并按 YouTube 和 Bilibili 原生章节分组
- 提取 Bilibili 视频提供的全部字幕语言
- 按 Bilibili 原生章节分组显示字幕
- 在 Chrome 原生侧边栏显示字幕
- 自动把字幕面板嵌入 YouTube 和 Bilibili 视频右侧
- 网页内字幕窗口可独立滚动，默认不会跟随播放位置跳动
- 点击字幕跳转视频时间
- 自动跟随当前播放位置
- 搜索、复制带时间戳的字幕
- 打开 Bilibili 视频后在后台持续读取主评论和楼中楼回复，主评论与楼中楼合计最多 500 条，可随时复制当前结果，页面不会自动滚动
- 评论区域显示本次加载的数据量和请求次数，复制已加载结果不会重复计量
- 下载 SRT 或 TXT
- 字幕只保存在当前浏览器会话的内存中

## Bilibili 首页工具

- 首页自动隐藏广告卡片和左侧大轮播推广，不再显示顶部工具栏和过滤开关。
- 原生“换一换”下方显示两个箭头：← 上一批推荐，→ 下一批推荐。支持最近 10 次历史，抵达两端时相应按钮自动禁用。
- 历史只保留在当前页面内存中，刷新/关闭页面后清空；安装前已经换掉的推荐不在记录内。
- 恢复的是推荐卡片的标题、封面、UP 主链接和视频链接；历史卡片点击可打开视频，不复刻原生悬停预览和“不感兴趣”等菜单。
- 只处理桌面首页，不过滤视频内口播广告，不拦截请求，不改写站点播放器/评论接口。

## 本地安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个 `caption-lite` 文件夹。
5. 将 Bili Kit 固定到工具栏。

## 使用方法

### YouTube

1. 打开并播放一个有字幕的 YouTube 视频。
2. 点击工具栏里的 Bili Kit 图标打开侧边栏。

扩展会自动读取视频提供的手动字幕和自动生成字幕；YouTube 页面内切换视频时也会自动更新。

### Bilibili

1. 打开 Bilibili 视频页面。
2. 点击 Bili Kit 图标。
3. 扩展会自动读取视频提供的字幕列表。
4. 评论会在视频打开后自动后台加载；加载过程中可以随时复制当前已加载的结果，复制不会因此停止后台加载。
5. 主评论和楼中楼回复合计达到 500 条时会立即停止加载，按钮显示“复制 500 条（上限）”；如果视频不足 500 条且自然加载完，按钮仍显示“复制全部 N 条”，之后仍可重复复制完整结果。

部分 Bilibili 字幕只有登录后才能读取。

网页内字幕面板会显示在“弹幕列表”上方。读取评论全程不会滚动页面；网络波动、限流或分页游标暂时异常时会保留当前结果并自动重试。

修改本地代码后，需要先在 `chrome://extensions` 点击 Bili Kit 的刷新按钮，再刷新视频页面。

## 评论流量统计

打开、刷新或切换视频后开始新一轮统计；接口重试继续累加，反复复制已加载评论不增加请求。统计覆盖插件发起的视频信息、签名密钥、主评论及楼中楼请求，不包含视频、图片、字幕或网站自身的评论请求。折叠面板后可悬停评论复制按钮查看统计说明。

- **评论传输**：全部已结束请求都有可读的浏览器 Resource Timing 大小时，显示响应头和响应体累计大小；缓存命中的传输量为 0。
- **评论数据（解压后）**：跨域等原因使部分请求缺少传输记录时，显示已读取响应体字节数，不把它当作实际网络流量。悬停可看已计量请求比例、缓存命中和异常次数。
- 使用十进制单位，1 KB = 1000 B；不统计请求上传、TLS 等协议开销，也不声称等同运营商账单。中断或读取失败时会注明数据可能不完整。
- 页面刷新后旧记录不保留；本次没有更改既有重试策略或 500 条评论上限。

口径参考：[MDN transferSize](https://developer.mozilla.org/en-US/docs/Web/API/PerformanceResourceTiming/transferSize)。

## 测试

项目没有第三方依赖。若本机已安装 Node.js，可运行：

```bash
npm test
```

浏览器流量回归（本地 gzip、跨域和缓存样本）：

```bash
python3 tests/comment-traffic.server.py
```

然后在 Chrome 打开 `http://127.0.0.1:8771/tests/comment-traffic.browser.html`，页面应显示 `ALL 15 CHECKS PASSED`；此数据是测试样本，不代表 Bilibili 视频的实际用量。

## 已知限制

- 仅支持 YouTube 和 Bilibili，不会把无字幕视频自动转录成文字。
- YouTube 或 Bilibili 修改播放器接口后，抓取代码可能需要更新。
- 本项目用于个人学习，不包含 vCaptions 的品牌、图标、账号或后端服务。
